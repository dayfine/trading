The fix asserted `[[ -e ]]`. **`[[ -e ]]` dereferences symlinks.** A **dangling symlink**
is invisible to it, and `find` on a dangling symlink exits 0 — so the reviewer measured
the *fixed* code passing vacuously again: **60/0/rc=0**. F2 recurring in narrowed form.

It also found the fix's **own new heredoc** unguarded, killing the suite with no summary
line — the exact class F1 closes, one line below F1's own fix.

The rework widened the predicate to **`-e || -L`**. The re-review then enumerated **23

route. Crucially it gave the *reason* rather than the sample: `! -e && ! -L` is exactly

path string, so the two cannot disagree. It also flagged that a plain `chmod 555`
unwritability probe returns a **false green for uid 0**, which anyone reproducing this
needs to know.
