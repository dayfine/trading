### Root cause 1 — parallel agents share ONE working tree

Step 4's GHA dispatch model states: *"branches are independent so parallel runs do not
collide on the working tree."* **This is false in this container.** There is a single
checkout at `/__w/trading/trading`. Observed directly this run:

- A single `git status` showed **both** agents' edit sets simultaneously.
- `git branch --show-current` reported one agent's branch while the *other* agent's
  uncommitted edits sat in the same tree.
- One agent ran a tree-wide `git add`, which **staged my orchestrator files**
  (`dev/budget/*.json`, `dev/health/*.md`) into its index — twice. I had to move my own
  files outside the repo to protect them.
- The code-health agent's edits **vanished entirely** at one point (no stash, no commit)
  — almost certainly a tree-wide revert during its mutation experiment. It redid them.
- The code-health agent independently reported: *"another agent ran a `git checkout` in
  the same shared container working tree, which silently switched `HEAD` out from under
  me while my edits were uncommitted."*

I mitigated mid-flight by messaging both agents with explicit path-limited staging rules,
and later by running all QC agents in strict read-only mode (`git diff origin/main...`,
`git show <ref>:<path>` — no checkout at all). Both PRs then landed clean commits.

**This is the most probable explanation for the whole stall**: prior runs dispatched two
parallel agents into one tree, they clobbered each other, and neither produced a pushed
commit. It is a spec defect, not an agent defect.

### Root cause 2 — #2169 was unmergeable for a reason nobody had checked

#2169 was `mergeable_state: dirty`. That is *why* **no CI check-suite ever ran on it**:
`pull_request` workflows execute against the computed merge commit, and GitHub could not
compute one. Every prior run waited on CI that could never start.

The conflict existed because **the PR's base commit was already redundant** — the
H-AUDIT-ATOMIC-WRITE fix itself (`mktemp`, `mv -f`, the abort hook, scenarios 19/20) had
independently landed on main via **#2163**. Verified: `git diff origin/main 993a1437 --
write_audit.sh` is **empty** — byte-identical.

Resolution: rebased onto main in a throwaway `/tmp` clone (so as not to disturb the
running agent's tree), dropping the redundant base and keeping only the N1 rework. CI
then ran and went green immediately.
