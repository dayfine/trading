### backtest-infra — #2113, the four-run flake, root-caused

Run 3 saw it red 3/3; runs 1, 2, 4 and 07-27 run 1 saw it green. Run 4 eliminated two hypotheses by
reading source (Owl copies before `potrf`; the jitter cap is `1e-2` absolute, not ~0) and run 1
eliminated a third (CI's `_build` cache is not masking it — a cold uncached CI build ran the suite
clean). What was left was "non-finite kernel entries" or "a BLAS kernel difference".

Instrumenting the live failure settled it:

```
nonfinite = 0   maxabs = 1.0111   asymmetry = 0   diag[i] = 1.0111 for every i
pure-OCaml unblocked Cholesky on the SAME matrix: SUCCESS
  pivot[9]  = 0.0147   <- the order LAPACK reports as failing
  pivot[33] = 0.0118   <- minimum pivot
```

Hypothesis (a) is **dead**: the matrix is healthy and factors cleanly. `OPENBLAS_VERBOSE=2` then
named the culprit — `Core: Cooperlake` on a CPU that is not one. n<=32 is correct because it stays in
OpenBLAS's unblocked base case, which is exactly why **only the two tests that drive the GP past 33
observations** ever failed.

The fix replaces `dpotrf` with a pure-OCaml unblocked Cholesky, so the factorisation no longer depends
on the host BLAS kernel. **PR #2009 — which two prior runs called "stalled since 07-19" — actually
merged on 2026-07-26 (`944bad0`);** I confirmed that independently. Its diagnosis ("duplicated
observations push the kernel to the edge of PD") is simply not this failure: the matrix was never
near-singular. Its retry loop is what turned one bogus rejection into six and made this look like a
jitter-tuning question.

**The QC exchange raised the bar twice.** qc-behavioral decomposed the author's "6 of 8 new cases fail
pre-fix" into 2 errors + 4 failures and observed that **4 of the 6 fail on *any* host** — the durable
regression value, which the raw count hides. It then found the certified range stopped at n=64 while
n=100 is reachable (`(total_budget 100)` in a committed spec) and argued that under a defect the PR
itself proves is **discontinuous in n**, certifying the bottom two-thirds is not certification. And it
caught a regression test whose pre-fix margin was `1e-9` against a `1e-9` epsilon — detection decided
by rounding, on one of only four host-independent tests.
