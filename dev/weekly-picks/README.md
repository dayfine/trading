# Weekly pick records

Generated by `generate_weekly_snapshot` (M6.6). Layout:
`dev/weekly-picks/<system-version>/<YYYY-MM-DD>.sexp`.

Produced by running the Weinstein screener cascade on cached bars for a given
as-of date; consumed by `trace_picks` / `diff_picks` / `render_weekly_report`.

## 2026-11 backfill

`89a08b1fe/` holds the 13 Fridays missed between 2026-08-21 and 2026-11-13
(user decision 2026-11-15: backfill every missed week). It follows the 08-14
procedure (#2377): `generate_weekly_snapshot`, then `validate_weekly_snapshot`
(warehouse bars, 1,000 risk budget), then `render_weekly_report` to `.md` and
`.html`, with `portfolio.sexp` as the book.

**Where the files are.** The records print closes, entries and stops, so under
the EODHD terms (user decision 2026-11-14) the full `<date>.sexp/.md/.html`,
`<date>.validation.txt` and `universe-<date>.sexp` live in the private
`dayfine/trading-results` repo under this same path, at commit `afd8105`. This
repo keeps one `<date>-picks.md` per Friday: macro state, strong and weak
sectors, and rank / symbol / grade / score / sector for each list.

**Config: `record-config-overrides.sexp`**, not the live file, which is
unchanged. It is the record arm's config plus two hygiene gates from the live
file:

- Kept, all 24 `config_overrides` of
  `dev/experiments/record-kseed-2026-10-27/specs/rk-k0.sexp`, verbatim and in
  order: these are the record config, the reason for the backfill.
  - `enable_sim_entry_stoplimit`, `sim_entry_trigger_at_suggested`,
    `sim_entry_stoplimit_fresh_bar_only`, `sim_stop_exit_fill_on_trigger_bar`:
    simulator fill rules, inert on the snapshot path, kept so the file stays
    the record's.
  - `stop_anchor_at_entry_base`, `require_structural_stop`: the record's stop
    basis.
  - `entry_extension_max_pct 2.0`: the record's value; the live file also
    has 2.0.
  - `reject_declining_ma_long_entry true`: set by both files, same value.
  - `enable_short_side false`: the record trades no shorts, so the short list
    in these reports is for reading only.
  - `portfolio_config` (`max_position_pct_long 0.14`,
    `max_long_exposure_pct 0.70`, `min_cash_pct 0.30`): the record's sizing
    caps, which the generator also uses to size tickets.
  - `enable_laggard_rotation`, `laggard_rotation_config`,
    `stale_exit_after_days`: record exit rules, inert here because the book
    holds nothing.
  - `liquidity_config` (`min_entry_dollar_adv`, `min_hold_dollar_adv`),
    `max_one_share_class_per_issuer`, `split_dividend_guard`: record
    admission and data guards.
  - `macro_config breadth_direction`: the record's macro setting.
  - `cash_yield`, `cash_yield_fee_bp`, `dividend_crediting`: record
    accounting, inert on the snapshot path.
  - `screening_config tiebreak_seed 0`: the record's Seeded tie order, seed 0.
    `candidate_ranking` stays at main's default (Seeded), as the record
    leaves it.
- Kept from the live file, `sparse_tail_min_bars 10` /
  `sparse_tail_window_trading_days 15`: data hygiene (#2083 fix 1, the
  SNSE→FTH zombie ticker); the record does not set them.
- Kept from the live file, `rename_detect_min_overlap_days 5` /
  `rename_detect_match_fraction 0.95`: data hygiene (#2083 fix 2); the record
  does not set them.
- Dropped `extension_stop_config (2.0, 0.25)`: an exit rule the record does
  not arm.
- Dropped `resistance_lookback_bars 520`: the record runs the default (0).
- Dropped `candidate_ranking Quality`: superseded by the record's Seeded
  order with seed 0.
- Dropped `failed_breakout_tolerance_pct 0.05`: a screener rule the backtest
  reads too, and the record runs it at its default 0.0 (off). Without it,
  names that closed back below their breakout level stay on the list.
- Dropped `entry_through_band_pct 1.0`: the record runs the default (0.0).
- `Overlay_validator` accepted every field; none had to be dropped.
