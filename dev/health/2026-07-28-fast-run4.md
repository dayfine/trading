## Method

Per the reasoning runs 7, 1, 2 and 3 gave, the build gate is **CI evidence on an
exact SHA** rather than a local re-run: a full `dune runtest` costs 12-24 minutes
and would have contended with the dispatched agent for the container's 4 cores /
15 GB.

The cheap checks were invoked **directly**, not through `dune runtest`. That has
been load-bearing since run 3 (all of them were among the 23 rules whose dune
entries lacked `(universe)`, so a warm cache could serve a stale PASS). #2148
closed that class for currently-wired top-level rules and **#2155, merged this
run, closed it for subdirectories too** — but direct invocation remains the form
of the gate worth trusting, and it is cheap.

Exit codes were read **directly**, not via `cmd | tail; echo $?`. I made exactly
that mistake on my first attempt this run and redid it — the piped form reports
`tail`'s status, which is the `H-CHECK-SETE-DIAGNOSTICS` shape this repo tracks.
