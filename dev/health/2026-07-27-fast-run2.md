## Method note -- exit code only, in both directions

The gate is the **exit code**, never a `FAIL:` grep. This suite prints OUnit
`Error:` lines, not `FAIL:` -- so a `FAIL:`-matching gate would have reported
today's red main as green. Conversely, some linters print advisory text while
exiting 0 (the CC linter warns on `_ascii_chart` CC=16 and exits 0). Both
directions have now been observed in this repo.
