## Note on locating prior health reports

`ls -t dev/health/*.md | head -1` does **not** return the newest report on a GHA
runner -- `actions/checkout` flattens every tracked file's mtime, so `ls -t` sorts
name-**ascending** and returns the oldest. Measured this run; filed as issue #2850.
Use `ls dev/health/*.md | sort | tail -1` (ISO-dated names sort chronologically).
