file" -- the orchestrator spec's documented invocation
(`sh trading/devtools/checks/<script>.sh`) is path-incorrect, because

Recorded because a **2** here reads exactly like a check failure at a glance,
and the live-evidence rule for `[critical]` escalations makes the distinction
load-bearing: an exit code from a script that never ran is not a RED baseline.
Worth correcting in the spec's Step 6.2 snippet.
