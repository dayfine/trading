## Carried trap (still live)

`dune runtest` output contains **two `FAIL:` strings that are not failures** —
they sit inside `OK:` lines of the `sete_diagnostics_check` meta-linter, which
asserts *about* `FAIL:` lines. `grep -c 'FAIL:'` returns 2 on a green tree;
`grep -c '^FAIL:'` returns 0. Read the exit code directly and never through a
pipe (`cmd | tail` yields `tail`'s status, not dune's).
